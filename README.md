# Legacy Code Modernizer (Rule-Based Edition)

> **Note:** This project is a specialized **Rule-Based Transpiler** designed to modernize legacy PHP templates into modern React components without using AI or LLMs.

## 🚀 Overview

Legacy Code Modernizer is a high-performance, deterministic tool that parses legacy PHP code (mix of HTML, PHP logic, and inline styles) and converts it into clean, functional React code.

It uses a custom-built **Stack-Based Parser** and **Regex Engine** to handle nested structures, ensuring consistent and valid output for supported patterns.

## ✨ Features

### 1. Advanced Rule-Based Engine (No AI)

Unlike AI-based tools that can hallucinate, this engine uses strict syntax rules:

- **Stack-Based Parsing:** Correctly handles nested loops and code blocks (e.g., `foreach` containing `if` statements).
- **Array Conversion:** Automatically converts PHP Associative Arrays (`['key' => 'val']`) to JavaScript functional objects (`{ key: 'val' }`).
- **Logic Extraction:** Detects `if-else` variable assignments inside loops and converts them to **Ternary Operators** (e.g., `$status == 'active' ? ...`).

### 2. Modern UI & UX

- **Clean Professional Design:** A solid, distraction-free interface suitable for enterprise usage.
- **Instant Feedback:** Shows Complexity Score and comprehensive Transformation Notes immediately after parsing.
- **Side-by-Side Comparison:** View legacy input and modernized output simultaneously.

### 3. Syntax Handling

- **Variables:** `$var = "value";` → `const var = "value";`
- **Loops:** `foreach($users as $user)` → `{users.map(user => ...)}`
- **Functions:** `count($users)` → `users.length`
- **Styles:** Converts string styles (`style="color: red"`) to React objects (`style={{ color: 'red' }}`).

## 📊 Accuracy & Performance

This tool is optimized for **Presentation Logic** (View Layer) conversion.

| Component                | Accuracy | Notes                                                                               |
| ------------------------ | -------- | ----------------------------------------------------------------------------------- |
| **Variables & Strings**  | **100%** | Handles simple strings and concatenations perfectly.                                |
| **Loops (foreach)**      | **95%**  | Excellent handling of standard loops and nested HTML.                               |
| **Arrays (Associative)** | **90%**  | Converts `=>` syntax and brackets correctly; limits apply to deep nesting.          |

## 🛠️ Installation & Usage

### Prerequisites

- Node.js (v14 or higher)

### Setup

1. **Backend:**

   ```bash
   cd backend
   npm install
   node server.js
   ```

   _Runs on port 5001_

2. **Frontend:**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
   _Runs on http://localhost:5173_

## 📝 Example Transformation

**Input (PHP):**

```php
$title = "Dashboard";
foreach($users as $user) {
    echo "<tr><td>" . $user['name'] . "</td></tr>";
}
```

**Output (React):**

```jsx
const title = "Dashboard";
{
  users.map((user) => (
    <React.Fragment key={user.id}>
      <tr>
        <td>{user.name}</td>
      </tr>
    </React.Fragment>
  ));
}
```
